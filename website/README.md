# Operation N.U.R.D.L.E.S website

Scroll-snapping one-page site presenting the nurdle spill simulation: the incident, the spill
location, the threat to the ecosystem, and the drift animation with a day-by-day slider.

```bash
npm install
npm run dev       # http://localhost:5173/ulisses-2025-project/
npm run lint
npm run build
npm run deploy    # publishes dist/ to the gh-pages branch
```
